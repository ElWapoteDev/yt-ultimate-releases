# YT Ultimate 4.4.1

Actualización para Windows 10 y 11 de 64 bits.

## Correcciones

- Corrige el arranque del separador en desarrollo para que CALIDAD y la separación de stems carguen BS-RoFormer sin el error de `beartype` relacionado con `stft_window_fn`.
- El separador usa el intérprete y las opciones del proyecto, conservando el entorno virtual aunque el ejecutable de Python sea un enlace simbólico.
- Descarta argumentos heredados que pertenezcan a otro separador.
- Los mensajes de error dejan de mostrar códigos de color de terminal.

Se mantienen CALIDAD, los modos Intenso y Equilibrado, la biblioteca y los ajustes. CALIDAD conserva el stem vocal separado y modifica solo la instrumental; la separación por IA puede dejar artefactos.

## Instalación

Descarga **YT-Ultimate-Setup-4.4.1.exe** o usa **Ayuda → Buscar actualizaciones…**. Los archivos `.blockmap` y `latest.yml` son para el actualizador automático.

En desarrollo, cierra y vuelve a abrir la aplicación después de actualizar los archivos para que el servicio use el nuevo arranque.

## Validación

Pruebas de configuración y arranque del separador en macOS y Windows, conservación del intérprete del entorno virtual y limpieza de errores. Prueba real de CALIDAD con la configuración generada por el controlador de escritorio y procesada por `AppConfig.from_env()`, sin sustituir manualmente el comando del separador.

El instalador se genera y valida en macOS. Esta publicación no incluye una prueba de instalación en un equipo Windows.
